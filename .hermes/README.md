# Hermes runtime home

The sandbox image sets `HERMES_HOME=/home/sandbox/harness/.hermes`.
This directory holds gitignored runtime configuration, auth, memory, skills, and sessions.
The managed program and virtual environment live separately at `~/.local/lib/hermes-agent`.

See [Hermes onboarding](../docs/harnesses/hermes.md) for installation, provider links,
authentication, storage persistence, and recovery.
