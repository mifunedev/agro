Content judgment on the migration note (`docs/harnesses/pi.md:148-152`): it states the
removal from defaults, names `/delegate` as the bounded delegation procedure, states that
a running Pi session keeps the `workflow` tool until reload or restart, and states that a
global installation or an explicit `pi -e` argument still registers it. It does not claim
the tool is gone everywhere, which would be false.

Deliberate divergences preserved: `pi-autoresearch` is documented on the site and not in
the harness, and it survives untouched in every sentence it appeared in — including the
`pi -e` example, which now ends `…, or pi -e npm:pi-autoresearch@1.6.0`. This is not a
docs sync, and no other divergence was altered.
