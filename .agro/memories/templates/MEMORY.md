# MEMORY.md — Long-Term Memory

<!--
  Curated, durable memories across sessions. A session reads this when it needs
  durable context from an earlier session.
  What belongs here: a runtime decision or a lesson, with the evidence that
  produced it.
  What does NOT belong here: operator identity and standing preferences
  (USER.md), the agent's character (SOUL.md), architecture (the root
  AGENTS.md), or a compiled pattern (.agro/knowledge/patterns/).

  This file is a template. Copy it to .agro/memories/MEMORY.md and leave it
  empty of entries until a session finishes work worth remembering.
-->

This file starts empty. A session adds the first entry when it finishes work
worth remembering, using one bullet per entry. Date every entry. State the
action, then the evidence that proves it:

```text
- **<short title>** (YYYY-MM-DD): <what to do, and the evidence that proves it>
```

Never rewrite an entry to match a new opinion. Add a dated correction and state
what changed. An entry that a command can prove belongs in a probe instead.
