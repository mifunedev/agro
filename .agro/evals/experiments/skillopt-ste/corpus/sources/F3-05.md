## Summary

Stand up `.pi/` as a real project workspace for the pi-coding-agent CLI: OpenAI-default settings, branded startup banner, a path-protection extension, the canonical `harness-context` skill, and full vitest + CI wiring for the new test surface.

## Motivation

Pi shipped as a default-installed CLI in #233 but had no project configuration. Without `.pi/settings.json`, prompts, skills, or extensions, every pi session at the harness root started from zero. This PR scaffolds a working pi setup with sensible defaults and a small library of in-tree extensions/skills, and ensures all of it is exercised by tests in CI.

## Proposed Implementation

**`.pi/`** — new project-level pi config:
- `settings.json` — OpenAI provider/model defaults, model cycling list scoped to GPT/o-series, declared local resource paths
- `extensions/mifune-banner.ts` — replaces pi's startup header with a flush-left `MIFUNE` wordmark + `pi harness · github.com/ryaneggz/mifune` subtitle (transient repo URL pre-org-migration)
- `extensions/path-guard.ts` — `tool_call` interceptor that confirms before write/edit on sensitive paths (`.env*`, `secrets/`, `credentials.{json,yaml}`, `*.pem`, `*.key`, `id_rsa`/`id_ed25519`/`id_ecdsa`) and risky bash (`rm -rf`, `sudo`, `git push --force`, `git reset --hard`, bare `> /dev/sd*|nvme*|hd*|disk*`); blocks on decline
- `APPEND_SYSTEM.md` — generic system-prompt addendum (consumer-agnostic, no harness-specific paths)
- `prompts/review.md` — `/review` template
- `skills` and `rules` directory symlinks to `../.claude/skills` and `../.claude/rules` (single-source-of-truth pattern matching `.codex/`)

**`.claude/skills/harness-context/`** — new canonical skill explaining harness layout/conventions; reachable from pi via the `.pi/skills` symlink.

**Tests** — `.pi/extensions/__tests__/{path-guard,mifune-banner}.test.ts`, hand-rolled mock `ExtensionAPI` (no pi devDep). Pi source verified via `gh api`: tool names lowercase, write/edit canonical input key is `path`. Defensive `toLowerCase()` normalization included.

**CI wiring**:
- `vitest.config.ts` — extended `include` to `.pi/**/__tests__/**/*.test.ts`
- `.github/workflows/ci-harness.yml` — added `.pi/**`, `scripts/**`, `vitest.config.ts` to the trigger filter; new "Root tests" step runs `pnpm test:scripts` (also brings the previously-orphaned `scripts/__tests__/cron-runtime.test.ts` into CI).

Also includes the project-local Pi `plan-mode` extension (separately scoped, already entered in `[Unreleased]`).

86 tests passing across 6 files.
