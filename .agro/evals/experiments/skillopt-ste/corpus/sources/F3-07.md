## Problem

The Slack bot fails to post/update messages when responses exceed ~3,500 chars. Three cascading errors per failed run:

```
⚠ Slack respond error      An API error occurred: msg_too_long
⚠ Slack replaceMessage error  An API error occurred: msg_too_long
⚠ Slack setWorking error   An API error occurred: msg_too_long
```

## Root Cause

`MAX_MAIN_LENGTH = 35,000` in `packages/slack/src/main.ts`'s `createSlackContext()` is set to Slack's documented maximum, but the workspace enforces a much lower effective limit (~3,000–4,000 chars). Responses that succeed top out at ~3,000 chars in `log.jsonl`; failures start around 4,000+ chars.

## Fix

- Lower `MAX_MAIN_LENGTH` from 35,000 → 3,000 in both `respond()` and `replaceMessage()`
- When accumulated text is truncated, spill the full chunk to thread
- Add `msg_too_long` specific retry with aggressive 900-char fallback in both methods
- Lower `respondInThread`'s 20,000 threshold to 3,000 for the same reason
- Rebuild dist and commit `src/` + `dist/`
