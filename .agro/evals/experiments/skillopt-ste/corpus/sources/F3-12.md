## Summary

The repository's self-description has drifted across multiple files since the v0.7 convergence. Three independent directory trees (`docs/architecture/container-runtime.md:80-124`, `AGENTS.md:151-164`, `README.md:78-85`) describe paths that no longer exist; phantom heartbeat env vars (`HEARTBEAT_ACTIVE_START`, `HEARTBEAT_ACTIVE_END`, `HEARTBEAT_AGENT`, `HEARTBEAT_INTERVAL`) appear in both `docs/architecture/container-runtime.md` and `.devcontainer/.example.env`; `README.md:6` links the croner runtime to a moved spec file.

This issue tracks the doc-only audit pass that fixes residual drift, establishes `docs/architecture/container-runtime.md#repo-layout` as the single canonical home for the directory tree, and adds a `.claude/rules/repo-layout-source.md` guard to prevent the next round.
