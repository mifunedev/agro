## Problem

Autopilot already enforces a scoped self-edit boundary (`OWNED_PATHS` + `.oh/hooks/owned-surface-guard.sh`), and `/audit` Gate 1 already treats a missing required artifact as failure. But neither is written down as an explicit, reusable **registry** / **contract schema** that a proposal generator and the audit gate can point at. This is documentation/schema work over behavior the code already enforces.

## Deliverable

Two small, related specs:

**(a) Repair-operator registry** — name the three tiers already enforced:

- *Safe by default:* `.oh/skills/*`, `.oh/context/rules/*`, `.oh/evals/probes/*`, `.oh/crons/*.md`, docs, `AGENTS.md`/`CLAUDE.md` summaries.
- *Stronger gate required:* cron runtime, `scripts/ralph.sh`, autopilot/orchestrate runner logic, `.devcontainer/*`, GitHub Actions, permission / sandbox / Docker-socket behavior.
- *Human approval required:* credential handling, secret propagation, external publishing, Slack/browser messages sent externally, host-level access expansion, anything expanding authority or blast radius.

**(b) Per-task artifact-contract block** — a declarable spec block:

```text
required_artifacts
allowed_locations
forbidden_destructive_edits
verification_commands
acceptance_criteria
rollback_conditions
final_handoff_requirements
```

that task specs can declare and `/audit` can enforce (missing/unverifiable ⇒ failure, not a soft warning).

## Why this is signal (not noise)

It formalizes boundaries the code already enforces — incremental documentation + a small schema, not new runtime machinery. It gives the (deferred) proposal generator and the existing audit gate a shared vocabulary.

## Validation

- Registry tiers match the actual classes in `.oh/hooks/owned-surface-guard.sh` / autopilot `OWNED_PATHS`.
- One task spec adopts the artifact-contract block; `/audit` fails when a declared required artifact is missing.

## Dependencies

- **Depends on:** trace/event ledger RFC (context only); diagnostic report format.
- **Feeds:** formal harness proposal generator (deferred / Later).
