## Description

The Bash secret-exposure guard `.agro/hooks/deny-env-dump.sh` allows two `jq` commands that print the full process environment:

- `jq -n 'env'`
- `jq -n '$ENV'`

The guard denies the unquoted form `jq -n env` only because the `DENY` term for a bare `env` at the end of the command matches it. The quoted filter forms match no term. The advisor found this gap while grounding #1149.

## Steps to Reproduce

1. Run the hook with the command `jq -n 'env'`:

   ```bash
   jq -nc --arg c "jq -n 'env'" '{tool_input:{command:$c}}' | bash .agro/hooks/deny-env-dump.sh
   ```

2. Observe empty output. Empty output means `allow`.
3. Repeat with `jq -n '$ENV'`. Observe empty output.

## Expected Behavior

The guard denies a `jq` filter that reads the `env` builtin or `$ENV`.

## Actual Behavior

The guard allows both commands.

## Second false allow (merged from #1152)

### Description

The container-inspect guard in `.agro/hooks/deny-env-dump.sh` allows `docker inspect --format 'json' <container>` and `docker inspect -f 'json' <container>`. Both print the full container JSON, including `Config.Env`. The unquoted and double-quoted forms are denied.

Cause: the `DOCKER_FMT_UNSAFE` term for a `json` format value writes its quote class as `["\x27]` inside a single-quoted bash string. `grep -E` reads that class as the literal characters `"`, `\`, `x`, `2`, and `7`, not as a single quote. A single-quoted `json` value therefore matches no term.

The US-001 worker found this during #1149 (PR #1151). The advisor confirmed it on the hook before and after #1151.

### Steps to Reproduce

1. Put the command `docker inspect --format 'json' web` in a file.
2. Feed it to the hook: `jq -nc --rawfile c <file> '{tool_input:{command:($c|rtrimstr("\n"))}}' | bash .agro/hooks/deny-env-dump.sh`.
3. Observe empty output. Empty output means `allow`.

### Expected Behavior

The guard denies a `json` format value in every quoting form.

### Actual Behavior

The guard allows the single-quoted form for `--format` and `-f`.

### Acceptance Criteria (from #1152)


- [ ] `docker inspect --format 'json' web` and `docker inspect -f 'json' web` are denied.
- [ ] `.agro/evals/probes/docker-inspect-env-guard.sh` asserts both single-quoted forms.
