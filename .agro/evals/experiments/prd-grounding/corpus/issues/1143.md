Publish SemVer pre-releases (for example `0.14.0-minimal.1`, later `0.14.0-rc.1`) through the existing `release.yml` pipeline, starting with `experiment/minimal-core`.

- Trigger `release.yml` on `experiment/**` pushes; an unbumped push stays a green no-op.
- Accept `MAJOR.MINOR.PATCH-<label>.<n>` versions.
- Mark the GitHub Release as a pre-release and never make it latest.
- Publish npm under the dist-tag `<label>`, never `latest`.
- Never promote a pre-release image to GHCR `latest`.

Out of scope: tag-push triggers, workflow_dispatch release path, moving GHCR channel tags, agro-web docs.
