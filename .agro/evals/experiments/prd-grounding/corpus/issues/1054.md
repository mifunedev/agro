## Summary

Retire `pi-dynamic-workflows` from the Open Harness default Pi configuration and current documentation. The package registers a `workflow` tool that duplicates the bounded delegation `/delegate` already owns. Retirement means removal from harness defaults, not a ban on operator-managed global or `-e` installations.

## Goals

- The default package list in `.pi/settings.json` excludes the dynamic workflow pin and preserves every other entry and setting.
- `.pi/extensions/__tests__/settings.test.ts` asserts the new exact list plus a negative package-identity assertion that covers alternate sources, not only the old commit string.
- Current documentation stops advertising the retired tool; a short migration note names `/delegate`, the reload boundary, and the global-override boundary.
- Pi regressions stay green and no global settings, cache, session, gateway, or provider mirror is touched.
- Distribution and public-documentation effects have an evidence-backed disposition.

## Non-goals

Do not modify Pi upstream, purge global installations, migrate user workflow scripts, add a replacement workflow engine, or remove unrelated orchestration tools.
