## User Stories

- As a **new AGRO user**, I want **one short line after my first successful `agro sandbox install`** that tells me where to star the project, so that **I can support it at the moment it helped me**.
- As a **CI or scripted user**, I want **no extra output in non-interactive runs and an opt-out variable** so that **automation output stays stable**.

---

## Summary

After `agro sandbox install` succeeds (after the `next: agro shell <name>` line), print once per machine:

```
⭐ If AGRO helps, star https://github.com/mifunedev/agro
```
