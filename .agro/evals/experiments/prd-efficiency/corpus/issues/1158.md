## Description

Reduce the issue templates to three, one per branch prefix: `feat`, `bug`, `task`.

- Rewrite `bug.md` in the `feat.md` shape: Metadata, Impact, Reproduction, Suspected Cause, TDD test plan, binary acceptance criteria.
- Replace `task.md` with a thin template: Metadata, Description, Done When.
- Delete `audit.md` and `skill.md`. Audits are a skill you run; a new skill is a feat.
- Align the prefix and commit-type lists in the `/git` skill and `docs/contributing.md`.
