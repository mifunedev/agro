## Problem

AGRO's recurring structural shape is *schema'd envelope, prose-produced value*.
`simplicity-review.json`, `ui-evidence.json`, `delegate-graph.json`, the capability triad and the
`/retro` hypothesis table all have strict schemas and strict validators — and in every case the
validator checks the envelope while an agent reading prose produces the value. Nothing verifies
the agent produced it faithfully.

A second shape compounds it: *prose-specified determinism*. `audit skills`, `audit context`,
`audit eval-quality` and `wiki query` publish exact shell snippets inside Markdown for an agent to
transcribe, with no corresponding `.sh`.

## Proposal

Make the control plane able to consume typed, calibrated judgments from TypeSafe System One
(`jev-latest`), filling the value slot where AGRO already built the schema, the validator and the
neutral default.

Scope of this issue:

- A zero-dependency adapter at `.agro/scripts/typesafe.mjs` over the HTTP API
  (`POST https://api.typesafe.ai/v1/systemone`) — **not** the npm SDK, to preserve `.agro/cli`'s
  zero-runtime-dependency guarantee, avoid the `pnpm audit --audit-level low` pre-install gate, and
  keep skill scripts portable.
- `TYPESAFE_API_KEY` wired through `SECRET_KEYS` and `.example.env`, deliberately **not** through
  the compose `environment:` block.
- A skill preflight so an unconfigured sandbox is reported up front rather than as an opaque 401.
- One proven consumer: `prompt-miner`'s `correctionDensity`, replacing a 12-word negation lexicon
  that `references/scoring.md` already flags as the highest-variance signal.
- Probe coverage guaranteeing AGRO behaves exactly as today when TypeSafe is absent.

## Contract

Unconfigured **fails loudly, then continues**: a specific diagnostic naming the cause and the fix,
exit 0, deterministic fallback. Never a silent fallback, never a crash.

## Out of scope

Skill suggestion via `UserPromptSubmit` (needs `/architect` + an ADR; Jev's literal reading makes
AGRO's dense `TRIGGER when:` prose a poor input shape without rewriting 36 descriptions),
model-assisted guard hooks (security boundary, adversarial input), `/wiki query` reranking
(explicitly forbidden in `references/query.md`), Tier-B behavioral evals.
