## User Stories
- As a Pi bridge operator, I can copy a YAML Slack app manifest into Slack without changing its permissions or commands.

## Summary
Replace the tracked `.pi/install/slack-manifest.json` with YAML and update all current documentation and eval references. Leave Pi runtime JSON configuration unchanged.

## Acceptance Criteria
- Slack manifest YAML parses and preserves all fields and values from the JSON manifest.
- Active docs point to the YAML file and no active reference points to the removed JSON file.
- Slack admin command probe verifies the YAML manifest and passes.
- Repository checks pass.
