## Proposed scope

Three independent decisions, each resolvable on its own:

1. **NOTICE files** — confirm whether the product rename belongs in a legal notice at all. The answer may be no, in which case record it and close that class permanently.
2. **Slack manifest** — check the live registered application before editing. If the name is registered, either leave it or coordinate a rename with the Slack app.
3. **Knowledge pages** — run the rename through `/wiki` so each page's re-verification happens by procedure, not as a side effect of a sweep.

Unit names stay. The earlier cutover already settled that, and this issue does not reopen it.
