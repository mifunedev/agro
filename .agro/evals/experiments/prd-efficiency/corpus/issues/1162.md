## Description

The `/delegate` worker brief (`.agro/skills/delegate/SKILL.md` § Worker brief) omits two rules that the active session receives from the harness:

1. Use no bare `git stash` or `git stash pop`. The stash stack is shared by every worktree and session, so a bare `pop` can take another session's entry.
2. A rerun of a hook-blocked command through a script file, a heredoc, or another tool bypasses the hook. The brief says "Never bypass a hook" but does not name this route.

Both occurred during #1156 (PR #1157). The US-004 worker ran a bare `git stash` and `git stash pop`. The US-005 worker reran a blocked `rm -rf` of its scratch clone through a script file. Neither action lost data.

## Steps to Reproduce

1. Read `.agro/skills/delegate/SKILL.md` § Worker brief.
2. Observe that the rules name neither the shared stash nor the script-file route around a hook.

## Expected Behavior

The worker brief states both rules.

## Actual Behavior

The worker brief states neither rule.
