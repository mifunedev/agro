## Summary

Use `harness` instead of `default` as the implicit host workspace directory for host harness installation and `agro workspace create`.

## Problem

Host installs without an explicit workspace resolve `~/.agro/workspaces/default`, unlike the sandbox harness directory name. The implicit `agro workspace create` name must match that install fallback.

## Acceptance Criteria

- An unconfigured host install resolves `~/.agro/workspaces/harness`.
- `agro workspace create` without a name creates `~/.agro/workspaces/harness`.
- Explicit `default` workspaces and previously recorded `harnessRoot` values continue to work.
- CLI help, docs, and tests reflect the new fallback.
