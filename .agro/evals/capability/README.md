# Capability benchmark

This benchmark measures demonstrated end-to-end capability, not regression coverage.
The [probe suite](../README.md) measures the regression floor.

| Path | Purpose |
| --- | --- |
| `tasks/CB-NNN-<slug>.md` | Task deliverables, rubrics, and real-instance references. |
| `RESULTS.md` | One current row per task; history retains earlier scores. |
| `run.sh` | Validate supplied axes, compute scores, and replace a task row. |

Read [AGENTS.md](AGENTS.md) before changing tasks or evidence.
The [source benchmark reference](https://github.com/mifunedev/agro/blob/main/docs/capability-benchmark.md)
contains scoring math, commands, and hand-scored limitations.
